路径设置

每个工具一张卡片，默认收起；展开后看本地路径、版本，可更改路径、自动检测或下载。

ASE GUI 不需要单独路径：直接复用上面的 Python 环境，命令是 python -m ase gui。 ASE / MACE / PyTorch / matplotlib / spglib / pymatgen 也都在这个 Python 环境里；pyIAST 等额外包需要时用同一个解释器 pip install 安装，不单独占路径卡片。 Avogadro / RASPA2 / Zeo++ 是可选工具，没装不影响结构体检、MACE、QE 主流程；Jupyter 按当前计划暂搁置。
不要把端口改成 0.0.0.0 后暴露到公网。这是单机工具，没有登录系统。
