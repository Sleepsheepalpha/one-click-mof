# 第 11 章：结果验证与报告

## 本章目的

学完这一章，你应该能：

- 判断一批数据能不能写进论文；
- 写清方法、参数、误差、复现；
- 做一张审稿人挑不出硬伤的图表；
- 知道哪些结论只能写“趋势”，不能写“绝对值”。

## 计算背景速查

| 词 | 计算含义 |
|---|---|
| 误差预算 | 每个近似大概贡献多少误差 |
| 交叉验证 | 用另一种方法/实验对照 |
| 可复现 | 别人按你的输入/参数能重跑 |
| 方法段 | 论文里写“怎么算的”那一段 |
| 支持信息 | 输入、参数、原始数据、图 |

## 论文级检查清单

### 结构

- [ ] CIF 来源、是否去溶剂/补 H/活化；
- [ ] 原胞/常规胞、原子数、密度；
- [ ] 金属配位/价态是否合理；
- [ ] 是否有无序/部分占据。

### 能量

- [ ] 泛函/色散（PBE-D3）；
- [ ] 赝势/截断/ecutrho；
- [ ] k 点；
- [ ] degauss；
- [ ] conv_thr；
- [ ] nspin；
- [ ] 参考分子/盒子；
- [ ] BSSE 是否讨论；
- [ ] ZPE/熵/ΔG；
- [ ] 误差棒。

### 等温线

- [ ] 来源（GCMC/IAST/Langmuir/实验）；
- [ ] 力场/电荷；
- [ ] 温度/压力范围；
- [ ] 单位；
- [ ] 拟合参数/R²；
- [ ] 与实验对照。

### 图

- [ ] 坐标轴单位；
- [ ] 图例；
- [ ] 误差棒；
- [ ] 字号/线宽；
- [ ] 图注写清方法/T/P；
- [ ] PDF + 300 dpi PNG。

## MOF-5 基准算例：一页报告模板

    # MOF-5 对 CH4 的吸附：DFT + 等温线

    ## 方法
    - 结构：IRMOF-1 原胞，106 原子，PBE-D3，SSSP，50/400 Ry，Γ。
    - 分子：CH4 / C2H6 / C6H6；参考分子与复合物同晶胞、同坐标。
    - 位点：MACE 预筛 24 个，top 2 做 DFT 单点，top 1 局部弛豫。
    - 等温线：298 K，0.01–10 bar，Langmuir（GCMC 未跑）。

    ## 结果
    - E_ads = -0.7161 eV（CH4，0 K，固定骨架）。
    - E_ads = -0.7205 eV（CH4，局部弛豫，max|F|=0.0013 Ry/au）。
    - ΔG_ads(298 K, 1 bar) = -0.145 eV（估算：S_ads≈0，无 ZPE）。
    - 饱和容量 = 5 mmol/g（假设值，非实验）。

    ## 误差
    - 泛函/色散：±0.1–0.2 eV。
    - BSSE：±0.05–0.2 eV（苯更明显）。
    - k 点/截断：±0.03–0.08 eV。
    - 固定骨架：±0.05–0.1 eV。
    - **本算例另有系统性过绑：绝对值比文献量级强 3–5 倍，见第 6 章合理性检查。**

    ## 复现
    - 输入/输出：tutorial/benchmark/mof5/runs/...
    - 版本：QE 6.7MaX、ASE 3.29、MACE 0.3.16。
    - 日期/作者：

## 怎么判断能写进论文

- 所有数都能追到原始输出；
- 参数一致，误差写清；
- 有对照（实验/文献/更高等级计算）；
- 结论没有超出数据（例如只算了 1 个位点，不能说“整个材料”）；
- 图和表自洽（同一单位/同一条件）。

## 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 审稿人问 BSSE | 没算/没讨论 | 至少加一段讨论/估算 |
| 审稿人问 k 点 | 只跑 Γ | 做 2×2×2 或说明理由 |
| 图和表数字不一致 | 版本/单位错 | 用同一 CSV 出图和表 |
| 结论过大 | 只算一个位点 | 改“该位点”/“候选” |
| 无法复现 | 缺输入/参数 | 保存 job 目录/哈希 |

## 练习

1. 用模板写一页 CH4 报告（数值可占位）。
2. 给你的图加误差棒和图注。
3. 列一张“审稿人可能问的 10 个问题”。

## 练习答案

1. 一页报告至少包含：结构/分子/方法、E_ads/ΔG、等温线来源、误差、复现路径。数值可占位，但方法/单位/标准态不能空。
2. 误差棒来自拟合/统计/误差预算；图注写温度、压力、方法、力场/模型、单位。没有误差棒就写“统计误差未估计”，不要假装没有。
3. 可列的 10 个问题：参考能怎么来；BSSE；k 点；截断；D3；nspin；覆盖度；等温线来源；选择性定义；能否复现；与实验对照；位点是否唯一。选 10 个写进报告。
