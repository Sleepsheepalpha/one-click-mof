# 第 12 章：one_click_mof 网页实操

## 本章目的

学完这一章，你应该能：

- 启动 one_click_mof，建立项目，扫描文件；
- 知道每个工具“做什么/吃什么/输出什么”；
- 设置参数、加入队列、启动、看日志、看指标；
- 知道当前工具有哪些限制，什么时候要手工替代。

## 计算背景速查

| 词 | 计算含义 |
|---|---|
| 项目 | 一组输入文件 + 默认参数 |
| 扫描 | 列出目录里的 CIF/QE/XYZ，不跑计算 |
| 队列 | 待运行任务列表；加入不等于运行 |
| manifest | 工具说明书：参数、命令、输出、解析 |
| 解析器 | 从输出里读能量/收敛/指标 |
| 保存点 | 长任务中断后继续 |

## 当前工具一览

| 工具 | 输入 | 做什么 | 限制 |
|---|---|---|---|
| 结构体检 | .cif | 原子数/密度/CN/短接触 | 不判价态 |
| 同晶胞参考 | .cif | 从复合物末尾取出吸附质，保留同晶胞/同坐标，生成 reference.cif | 吸附质必须在 CIF 末尾 |
| MACE 位点筛选 | .cif | 随机撒点 + MACE 局部优化，给每个位点的 E_ads | 只筛位点/排序，不算热力学；自定义分子要自带 XYZ |
| 结构转 QE 输入 | .cif/.xyz/.vasp | 生成 mof.in | 固定骨架时要指定尾部可动原子数（默认 3，CH4 要 5） |
| QE 单点 | .cif | 跑 pw.x | 参数要自己保证一致 |
| QE 局部弛豫 | .cif | 只弛豫尾部 N 个原子，骨架固定 | 分子必须在原子列表末尾；N 要设对 |
| QE 运行已有输入 | .in/.pwi | 跑现成输入 | 不检查一致性 |
| MD 分析 | .xyz | MSD/D/RDF | 分子识别按元素/连通性，复杂体系要核对 |

## 做法

1. 启动：

    python3 one_click_mof/app.py --port 8765

2. 浏览器打开 http://127.0.0.1:8765。
3. 路径设置：Python、pw.x、mpiexec、赝势、模型；结构可视化常用 VESTA。Avogadro、RASPA2、Zeo++ 是可选项，ASE GUI 复用 Python 环境（`python -m ase gui`）。
4. 新建项目：输入目录选 tutorial/benchmark/mof5/inputs。
5. 扫描目录。
6. 选文件 → 选工具 → 改参数 → 加入队列。
7. 运行队列 → 启动队列。
8. 看日志/指标；结果筛选/导出 CSV。

## 参数表（常用）

| 工具 | 参数 | 默认 | 说明 |
|---|---|---|---|
| MACE | n_sites | 24 | 起点数 |
| MACE | seed | 固定 | 复现 |
| MACE | device | cuda | 无 GPU 改 cpu |
| QE 单点 | np | 6 | MPI 进程 |
| QE 单点 | ecutwfc/ecutrho | 50/400 | 收敛测试 |
| QE 单点 | degauss | 0.02 | bare/complex 必须一致 |
| QE 单点 | conv_thr | 1e-4 | 大体系常用 |
| QE 弛豫 | nstep | 50 | 到上限不是崩溃 |
| QE 弛豫 | forc_conv_thr | 1e-3 Ry/au | 看最终力 |

## MOF-5 基准算例

### 已可做

- 结构体检：选 IRMOF-1_primitive.cif → 结构体检 → 看 natoms=106、Zn CN=4。
- 同晶胞参考：选带吸附质的复合物 CIF → 填分子原子数（CH4=5）或骨架原子数（MOF-5 原胞=106）→ 生成 reference.cif。

### 当前做不了/要手工

- MACE 筛选任意分子：选 `adsorbate=CH4/C2H6/C6H6/CO2`，或给自定义 XYZ。
- QE 弛豫任意分子：把 `movable-atoms` 设成分子原子数（CH4=5、C2H6=8、C6H6=12）。
- MD 运行：网页只有分析，没有运行器 → 用命令行/等 P1。

### 结果记录

## 怎么判断成功

- 项目建立后能看到文件；
- 任务目录有 input/run.log/job.json/metrics.json；
- 日志里能看到命令和输出；
- 指标页能读到能量/收敛；
- 你知道哪些步骤是工具做的、哪些是手工的。

## 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 加入队列没跑 | 没点“启动队列” | 去运行队列启动 |
| 文件扫描不到 | 后缀/目录不对 | 看 manifest accepts |
| QE 找不到赝势 | 路径/相对路径 | 用绝对路径 |
| 任务 OOM | np 太大/体系太大 | 减 np、40/320 |
| 结果页没指标 | 解析器不认输出 | 看 run.log/parser |
| 长任务中断 | 没开保存点 | 开 checkpoint 重跑 |

## 练习

1. 建一个 MOF-5 项目，扫描 inputs，跑结构体检。
2. 看一个任务的 job.json，找到命令和参数。
3. 故意把 pw.x 路径改错，看日志报什么。

## 练习答案

1. 新建项目→输入目录选 tutorial/benchmark/mof5/inputs→扫描→选 IRMOF-1_primitive.cif→结构体检→启动队列；结果 JSON 应显示 natoms=106、Zn CN=4。
2. job.json 里应有 tool_id、params（np/ecutwfc/degauss 等）、命令、输入/输出路径、时间；用它复现任务。
3. pw.x 路径错时，run.log 会出现 FileNotFoundError/command not found，任务状态 failed；改回 /usr/bin/pw.x 后重跑。
