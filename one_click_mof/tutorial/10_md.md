# 第 10 章：MD 与稳定性（选做）

## 本章目的

学完这一章，你应该能：

- 判断什么时候需要 MD，什么时候不需要；
- 设置 NVT、温度、时间步、平衡段/生产段；
- 看 MSD、D、R²、RDF、配位数、分子完整性；
- 知道“一次跳跃”不等于“稳态扩散”。

## 计算背景速查

| 词 | 计算含义 | 为什么重要 |
|---|---|---|
| MD | 分子动力学：让原子按力随时间动 | 看 298 K 下稳不稳 |
| NVT | 固定原子数、体积、温度 | 最常用 |
| NPT | 固定压力，体积可变 | 看骨架会不会收缩 |
| 恒温器 | 控制温度的算法 | Langevin/Nose-Hoover |
| 时间步 dt | 每步走多久 | 0.5 fs 常用 |
| MSD | 分子跑了多远（均方位移） | 扩散分析 |
| D | 扩散系数 | 只有 MSD 线性区才有意义 |
| R² | 拟合好坏 | 太低不要报 D |
| RDF | 径向分布函数 | 看局部结构 |
| 停留时间 | 分子在一个位点待多久 | 比 D 更直观 |

## 什么时候需要 MD

- 想看 298 K 下分子会不会脱附；
- 想看骨架会不会塌/金属会不会迁移；
- 想看扩散、停留、氢键；
- 论文审稿人要求动力学证据。

**不需要**：只比较 0 K 吸附能、只做筛选。

## 做法

1. 从 DFT 或 MLIP 优化结构出发；
2. 选系综（NVT/NPT）；
3. 设温度、dt、步数；
4. 平衡段（丢弃）；
5. 生产段（分析）；
6. 算 MSD/D/RDF/完整性；
7. 检查能量漂移、温度、骨架。

## 参数表

| 参数 | 作用 | 默认 | 怎么调 |
|---|---|---|---|
| ensemble | NVT/NPT | NVT | 看体积变化用 NPT |
| T | 温度 | 298 K | 按应用 |
| dt | 时间步 | 0.5 fs | 含 H 体系不要 >1 fs |
| steps | 总步数 | 100,000（50 ps） | 先 10 ps 试 |
| thermostat | 恒温器 | Langevin | friction 0.05/fs |
| 平衡段 | 丢弃前段 | 5–10 ps | 看能量/温度平台 |
| 生产段 | 分析段 | 20–50 ps | 越长越好 |
| 负载 | 分子数 | 1–4 | 与实验/等温线对应 |

## MOF-5 基准算例

### 计划

- 体系：MOF-5 + CH4（1 个）。
- 298 K，NVT，dt=0.5 fs，10 ps 试跑。
- 检查：温度、能量漂移、CH4 完整性、CH4 到骨架距离。

### 结果表（未跑）

| 量 | 值 | 备注 |
|---|---:|---|
| 平均温度 | 未跑 | K |
| 能量漂移 | 未跑 | eV/10 ps |
| CH4 完整帧 | 未跑 | /总帧 |
| MSD@10ps | 未跑 | Å² |
| 表观 D | 未跑 | m²/s，R² 低就不报 |
| 最小 CH4–骨架距离 | 未跑 | Å |

> 本教程没有跑 MD：MOF-5 + CH4 的 50 ps NVT 需要额外几小时到一天，而且要先验证力场/电荷。

## 怎么判断成功

- 温度在目标附近，能量没有大幅漂移；
- 分子没断键/没飞走；
- 骨架金属 CN 没有大幅变化；
- MSD 最后一段线性才报 D；否则只说“局域跳跃/受限”。

## 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 温度飞了 | dt 太大/恒温器错 | 减小 dt、检查设置 |
| 能量一直降 | 没平衡 | 延长平衡段 |
| 分子解离 | 力场/模型错 | 换模型、检查几何 |
| D 很大但 R² 很低 | 一次跳跃 | 不报 D，改停留时间 |
| 骨架塌 | 温度太高/力场错 | 降温、固定部分骨架 |

## 练习

1. 10 ps 试跑，画 MSD；判断有没有线性区。
2. 把 dt 从 0.5 改到 1.0，看能量漂移。
3. 解释为什么“1 个分子”的 D 不能代表材料本征扩散。

## 练习答案

1. 10 ps 往往还没有线性 MSD 区；只能报 MSD 和“表观 D”，并注明 R²。若最后一段不线性，不要报稳态 D，延长到 50 ps 或改看停留时间。
2. dt 1.0 fs 对含 H 体系更容易能量漂移/不稳定；0.5 fs 更安全。若必须 1.0 fs，需检查能量守恒和分子完整性。
3. 一个分子只有一条轨迹，采样有限；D 受负载、笼效应、统计涨落影响，不是材料本征值。至少多分子/多 seed/更长轨迹，并注明负载。
