# 第 9 章：吸附等温线与论文图

## 本章目的

学完这一章，你应该能：

- 选择等温线来源（Langmuir/IAST/GCMC/实验）并说明证据强度；
- 区分三类等温线方法的适用边界；
- 知道“DFT 单点不能直接画等温线”；
- 画出论文可用的 P–uptake 图，并写清方法。

## 计算背景速查

| 词 | 计算含义 | 为什么重要 |
|---|---|---|
| 计算等温线 | 用 GCMC/IAST/Langmuir 把能量/位点转成 P–uptake | DFT 单点只给一个能量点，不能直接给整条线 |
| 状态点 | 每个 (T, P) 对应一个吸附量；不是一条 0 K 曲线 | 压力范围/单位要写清 |
| Langmuir（计算） | 用位点密度 + ΔG 拟合 P–uptake | 最简单，但当近似；要报参数/R² |
| IAST | 用单组分等温线预测混合物 | 选择性常用 |
| GCMC | 巨正则蒙特卡洛，直接模拟吸附 | 需要力场/电荷，论文级 |
| 计算选择性 | IAST/竞争 GCMC 得到的吸附量比 | 需写混合气组成和定义 |
| 饱和容量 | 压力很高时最多吸多少 | 孔体积/位点数决定 |

## 三条路线

### 路线 A：DFT-informed Langmuir（教学/快速）

1. DFT 算 top 位点 E_ads；
2. 估算位点密度；
3. Langmuir：

    θ = bP / (1 + bP)
    b = exp(-ΔG_ads / RT) / P0

4. 画 P–uptake。
5. **明确写：这是近似等温线，不是 GCMC。**

### 路线 B：IAST（混合气/论文常用）

1. 每个纯组分等温线（实验/GCMC/Langmuir）；
2. 用 pyIAST 拟合；
3. 输入混合气组成；
4. 算选择性。

### 路线 C：GCMC（论文级）

1. 力场/电荷（UFF/DREIDING + DDEC/QEq）；
2. RASPA2 跑单组分/混合物；
3. 得到 P–uptake；
4. 与实验对照；
5. DFT 标定关键位点。

## 参数表

| 参数 | 作用 | 默认 | 怎么调 |
|---|---|---|---|
| T | 温度 | 298 K | 按应用 |
| P 范围 | 压力点 | 0.01–10 bar | log 扫描 |
| 模型 | Langmuir/IAST/GCMC | Langmuir | 论文级用 GCMC/IAST |
| 位点密度 | Langmuir 用 | 从结构估 | 不确定就做敏感性 |
| 饱和容量 | 最大 uptake | 孔体积估 | 与实验对照 |
| 力场/电荷 | GCMC 用 | UFF/DDEC | 必须验证 |

## MOF-5 基准算例

### 现状

> **警告**：第 6 章发现同晶胞参考有系统偏移（孔心 E_ads 应为 0，实测 CH4 -0.40、C2H6 -0.92、C6H6 -2.16 eV）。下面的 ΔG 和等温线只演示方法，数值不可引用。

- 结构/分子输入、DFT E_ads 已就位；
- 已经有 DFT-informed Langmuir 的输入（ΔG 来自第 8 章）；
- GCMC/IAST 未跑（需要力场/电荷和更多机时）。

### 路线 A：CH4 的 Langmuir 估算

参数：

- T = 298.15 K，P0 = 1 bar；
- ΔG = -0.093 eV（第 8 章，CH4）；
- q_sat = 5 mmol/g（按 MOF-5 孔容估的**假设值**，不是实验值）。

    K = exp(-ΔG / RT) = 37 bar^-1
    θ = K P / (1 + K P)
    q = q_sat · θ

### 结果表

| ΔG (eV) | K (bar^-1) | q(0.01 bar) | q(0.1 bar) | q(1 bar) | q(10 bar) |
|---|---:|---:|---:|---:|---:|
| -0.05 | 7.0 | 0.33 | 2.06 | 4.38 | 4.93 |
| -0.10 | 49 | 1.64 | 4.15 | 4.90 | 4.99 |
| **-0.093** | **37** | **1.36** | **3.94** | **4.87** | **4.99** |
| -0.20 | 2.4e3 | 4.80 | 4.98 | 5.00 | 5.00 |

单位：q 为 mmol/g。

### 这张表暴露的问题

按 ΔG = -0.093 eV，1 bar 时已经 97% 饱和，0.01 bar 就到 1.36 mmol/g。而 MOF-5 的 CH4 实验等温线在 1 bar 通常只有饱和容量的百分之十几，远没饱和。

两者对不上，可能的原因按优先级：

1. **E_ads 偏强**（第 6 章已经指出，-0.67 eV 比文献量级强 3–5 倍）。这是最可能的。
2. **ΔG 估计偏负**：第 8 章假设 S_ads ≈ 0，把熵罚算到了最大；真实 ΔG 应更接近 0。
3. **单点位 Langmuir 太粗**：MOF-5 有多个不等价位点、分子间相互作用，真实等温线不是单点 Langmuir。
4. **q_sat 假设错**：5 mmol/g 只是量级估计。

正确做法不是回头调 q_sat 把曲线压下去，而是先修 E_ads：按 min_mol_framework ≥ 3.0–3.2 Å 重筛位点、重算 DFT，再看等温线是否回到实验量级。

> 这就是为什么第 6 章要单独做“物理合理性检查”。如果直接拿 -2.44 eV 的苯去画等温线，会得到一条 0.001 bar 就饱和的曲线，看上去“吸附很强”，其实是错的。

### 图件要求

- 横轴：P (bar)，log 或线性；写清。
- 纵轴：uptake (mmol/g 或 cm³(STP)/g)。
- 点：模拟/实验；线：拟合。
- 图注：温度、力场/模型、压力范围、误差。
- 保存：PDF + 300 dpi PNG。

## 怎么判断成功

- 能说清曲线来源（不是“DFT 自动画的”）；
- 单位和压力范围写清；
- 有实验/文献对照最好；
- 选择性有定义（IAST/亨利）；
- 图能直接放进论文（字号、单位、图注）。

## 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 等温线是直线 | 低压/亨利区 | 扩大压力范围 |
| 吸附量 > 孔体积上限 | 单位/密度错 | 检查 mmol/g 换算 |
| Langmuir 拟合很差 | 多位点/相互作用 | 换 Sips/双位点 |
| 选择性和文献差很多 | 力场/电荷/组成不同 | 统一条件 |
| 把 E_ads 当 ΔG | 概念错 | 回到第 8 章 |

## 练习

1. 用 3 个假数据点拟合 Langmuir，手算 b 和饱和容量。
2. 解释为什么等温线常用 log P。
3. 查一篇 MOF-5 的 CH4 等温线，比较你的曲线。

## 练习答案

1. Langmuir 线性化：P/q = 1/(q_sat b) + P/q_sat。以 P/q 对 P 作图，斜率 = 1/q_sat，截距 = 1/(q_sat b)，所以 q_sat = 1/斜率，b = 1/(截距·q_sat)。三个点也能拟合，但 R² 和参数不确定性要报告。
2. 等温线常跨越几个数量级压力；log P 能同时显示低压亨利区和高压饱和区，线性轴会把低压区挤成一点。
3. 比较时至少统一温度、压力范围、单位（mmol/g vs cm³(STP)/g）和来源（实验/GCMC）。若你的曲线明显偏高，先查饱和容量/单位/力场，而不是先怀疑材料。
