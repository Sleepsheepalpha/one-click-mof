# 第 13 章：三个完整案例（CH4 / C2H6 / C6H6）

## 本章目的

学完这一章，你应该能：

- 把同一套流程套到三个不同分子；
- 识别每个分子的关键相互作用和计算坑；
- 比较三者的 E_ads/等温线，并解释差异；
- 写出一段“为什么 CH4 比 C6H6 弱”的讨论。

## 计算背景速查

| 词 | 计算含义 | 和哪个分子有关 |
|---|---|---|
| π–π 堆叠 | 苯环和骨架苯环面对面 | C6H6 |
| C–H···O | 分子 C–H 和骨架 O 的弱氢键 | CH4/C2H6 |
| 构象 | 乙烷交叉/重叠 | C2H6 |
| 极化率 | 电子云容易被扭曲的程度 | 苯最大 |
| BSSE | 基组重叠误差 | 苯最明显 |

## 案例 1：CH4

- 特点：小、球形、弱极化；E_ads 通常 -0.1 ~ -0.3 eV。
- 关键：位点搜索要够密；CH4 可能在一个孔里多个等价位点。
- 坑：E_ads 很小，截断/degauss/BSSE 的相对误差占比大。
- 论文写法：报多个位点，不要只报最强的一个。

## 案例 2：C2H6

- 特点：比 CH4 大、可变形；E_ads 通常 -0.2 ~ -0.4 eV。
- 关键：构象（交叉 vs 重叠）；C–H···O 接触。
- 坑：只算一个构象；位点被孔窗卡住。
- 论文写法：说明构象、取向、是否有多个接触。

## 案例 3：C6H6

- 特点：平面、极化率高、π–π 堆叠；E_ads 通常 -0.4 ~ -0.8 eV。
- 关键：D3 必须开；取向采样；BSSE。
- 坑：PBE 无 D3 严重低估；只算一个取向；基组不够。
- 论文写法：报取向、D3、BSSE、与实验/文献对照。

## 统一流程

1. 结构：MOF-5 原胞（106 原子）。
2. 分子：XYZ。
3. 位点：24 个起点，probe 2.2，固定 seed。
4. 预筛：MACE（先标定）。
5. DFT：top 3 单点；top 1 局部弛豫。
6. 热力学：ZPE/熵/ΔG（论文级）。
7. 等温线：Langmuir/IAST/GCMC。
8. 图/报告。

### 怎么读这张表

- **趋势**：CH4 < C2H6 < C6H6，和“分子越大、极化率越高、接触越多”一致。
- **数值**：不要直接和实验吸附热比较；都是 0 K 电子能（ΔG 列除外，但熵是估算）。
- **位点**：重筛后 MACE 和 DFT 都选 14 / 17 / 17，排序一致；上一轮不同位点，说明采样会改变结论，必须多起点。
- **可信度**：三个分子仍偏强 3–5 倍，且对接触距离不敏感，指向**系统性方法偏差**，不是某个位点的偶然。

## 怎么判断成功

- 三个分子用同一套结构/参数/参考；
- 趋势合理（苯通常最强，CH4 最弱）；
- 差异能用物理（大小/极化率/π–π）解释；
- 没有把某个分子的特例当普遍规律。

## 常见错误

| 现象 | 原因 | 处理 |
|---|---|---|
| 苯比甲烷还弱 | 没开 D3/取向少 | 开 D3；多取向 |
| 乙烷结果随构象跳 | 构象没固定 | 固定/都算 |
| 三个分子参考能不一致 | 盒子/截断不同 | 统一 |
| 只报一个位点 | 采样不足 | 报分布/top-N |

## 练习

1. 比较 CH4 和 C6H6 的 E_ads，解释差异。
2. 给苯加 3 个不同取向，看 E_ads 变多少。
3. 写一段 150 字的“三个分子趋势”讨论。

## 练习答案

1. 通常 C6H6 的 E_ads 比 CH4 更负：苯极化率大、π–π/色散作用强、接触面积大；CH4 小且弱极化。但具体排序取决于孔道和位点，不能只看分子大小。
2. 苯的 3 个取向可能差 0.1–0.3 eV；应报最低值/范围，并说明取向采样。若差 >0.5 eV，检查是否有一个取向嵌进骨架或未收敛。
3. 参考讨论：CH4 最弱（约 −0.1 ~ −0.3 eV），C2H6 中等（约 −0.2 ~ −0.4 eV），C6H6 最强（约 −0.4 ~ −0.8 eV）；差异主要来自极化率/接触面积/π–π 和色散。必须注明这些是数量级参考，不是本算例结果，且受位点/泛函/BSSE 影响。
